# موديلات الذكاء للعقود — Chronos-2 + TimesFM 2.5 + FinBERT

هذه الطبقة **اختيارية** فوق محرك عقود SPY/SPX التجريبي. لا تنفذ صفقة حقيقية ولا تحتاج Alpaca Key.

## الموديلات

- `amazon/chronos-2`: توقع احتمالي للسعر قصير المدى.
- `google/timesfm-2.5-200m-transformers`: توقع مستقل ثانٍ لتقليل الاعتماد على نموذج واحد.
- `ProsusAI/finbert`: يصنف عناوين الأخبار المالية إلى إيجابي/سلبي/محايد.

المحرك يجمع الأصوات مع الإشارة الفنية الحالية. إذا لم تكن الموديلات مثبتة أو فشل أحدها، يستمر البوت بالإشارة الفنية ويسجل أن القرار degraded بدل إيقاف Telegram أو محرك الـPaper.

## التثبيت على السيرفر

بعد تثبيت المتطلبات الأساسية:

```bash
python -m pip install -r requirements-models.txt
python -m telegram_bridge configure-options-models --device auto --cache-dir models
python -m telegram_bridge download-options-models
python -m telegram_bridge serve
```

أمر `download-options-models` ينزل الأوزان مرة واحدة إلى الكاش ويجرب تحميل كل موديل. الأوزان كبيرة (إجمالًا تقارب عدة جيجابايت مع ملفات الكاش)، لذلك لا تُرفق داخل ZIP.

بعد تشغيل البوت:

```text
/optionsmodels
/optionson
/optionsstatus
```

`/optionsmodels` يبين المكونات المتاحة وأي خطأ معزول. لا تعرض الرسالة مسار الكاش أو أي أسرار.

## كيف يتخذ القرار

الأوزان الافتراضية:

- Technical: 20%
- Chronos-2: 35%
- TimesFM 2.5: 30%
- FinBERT: 15%

إذا لا يوجد أي تصويت AI، يحتفظ المحرك بالإشارة الفنية السابقة كما هي. إذا توفرت أصوات AI، يعاد تطبيع الأوزان للمكونات المتاحة ويجب أن يتجاوز مجموع الاتجاه حد الثقة قبل Call أو Put؛ وإلا Hold.

أفق Chronos/TimesFM المستخدم للدخول يقارب 30 دقيقة (6 شمعات × 5 دقائق). FinBERT يستخدم حتى 8 عناوين حديثة يجلبها مصدر الأخبار keyless بطريقة best-effort؛ فشل الأخبار لا يمنع التسعير أو إدارة المركز.

## استهلاك الذاكرة

لتناسب سيرفر صغير، يتم تحميل موديل واحد في كل مرة من الكاش وإفراغه بعد التصويت. هذا يخفض الذروة مقارنة بإبقاء الموديلات الثلاثة في الذاكرة، لكنه يجعل كل دورة أبطأ. إذا كان السيرفر ضعيفًا جدًا فابقِ `options_models_enabled=false` وسيعمل محرك العقود الفني القديم.


## متطلبات السيرفر

ملف `compose.yaml` الافتراضي محدود بـ **512MB RAM** ومخصص لتشغيل البوت الأساسي بدون موديلات الذكاء. لا تشغّل Ensemble داخل هذا الحد. لتفعيل Chronos-2 + TimesFM 2.5 + FinBERT استخدم سيرفرًا أكبر وثبّت `requirements-models.txt` في بيئة Python قابلة للكتابة مع مساحة كافية للكاش. لأن الموديلات تُحمّل بالتتابع بدلًا من إبقائها كلها في الذاكرة، استهلاك الذاكرة أقل من التحميل المتزامن، لكن 512MB غير كافية.

## تنبيه
