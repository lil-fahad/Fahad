## تفعيل الشراء والبيع

أضيف ربط Alpaca للشراء والبيع بأوامر محددة بسعر، ومعاينة وتأكيد شخصي داخل Telegram، وعرض المحفظة ومتابعة الأوامر وإلغائها وإيقاف قبول صفقات جديدة. البداية بحساب تجريبي؛ الحساب الحقيقي يحتاج إعدادًا محليًا منفصلًا. دليل الإعداد والأوامر: [TRADING_AR.md](TRADING_AR.md).

بعد `setup`، شغّل `.venv/bin/python -m telegram_bridge configure-trading --mode paper` ثم `serve`. يطلب الإعداد مفاتيح Alpaca بحقلين مخفيين ويختار بيانات IEX للتوقعات. اختبارات الوسيط محاكاة؛ لا توجد صفقة فعلية أو حساب مربوط في هذه الحزمة.

## تفعيل التوقعات بصورة مستقلة

بعد تنفيذ `setup` في خطوات التثبيت أدناه، نفذ:

```bash
.venv/bin/python -m telegram_bridge configure-predictions --provider alpha_vantage
.venv/bin/python -m telegram_bridge serve
```

يطلب أمر الإعداد مفتاح بيانات السوق في حقل مخفي. لا ترسله في ChatGPT. إذا لديك إعداد من الإصدار السابق، أوقف الخدمة، واحتفظ بمجلد `private` وقاعدة البيانات، واستبدل ملفات البرنامج، وثبّت `requirements.lock` المحدث، ثم نفذ `configure-predictions` وأعد التشغيل. لا تعِد `setup` ولا تحذف قاعدة البيانات.

أرسل الأوامر في محادثتك الخاصة مع البوت بعد تشغيله:

| الأمر | النتيجة |
|---|---|
| `/predict AAPL 5` | احتمال الصعود، وسيط السعر، والنطاق التاريخي بعد 5 جلسات |
| `/predict MSFT 1` | توقع لجلسة واحدة |
| `/predict NVDA 20` | توقع لعشرين جلسة؛ يتطلب سجلًا أطول لتقييم كافٍ |
| `/backtest AAPL 5` | دقة الاتجاه، وخطأ العائد، وجودة الاحتمال، ومقارنة بسيطة |
| `/status` | حالة إعداد مصدر البيانات |
| `/help` | الأوامر المتاحة |

الرمز مطلوب؛ الأفق الافتراضي 5 جلسات، والمدعوم 1 أو 5 أو 20. هذه جلسات سوق وليست أيامًا تقويمية. لا يولّد البوت تاريخًا مستقبليًا تخمينيًا للعطلات. لا يحتاج الرد داخل Telegram إلى نطاق عام أو ربط ChatGPT؛ يكفي تشغيل البرنامج على كمبيوتر متصل بالإنترنت باستمرار. النطاق وOAuth مطلوبان عند إتاحة أدواته لـChatGPT عبر الإنترنت.

تفعيل التوقعات يسمح بردود الأوامر في المحادثات الخاصة المسموحة، مستقلًا عن أداة إرسال ChatGPT العامة. يبقى `allow_send` كما هو. لا تتفاعل الأوامر مع المجموعات أو النصوص المحوّلة أو الرسائل المعدّلة، ولا يوجد جدول إرسال. تنفيذ الصفقة يتطلب إعداد التداول وتأكيد صاحب الحساب وفق دليل TRADING_AR.md.

## مصدر البيانات وما تحقق بالفعل

| المصدر | التنفيذ في الحزمة | التحقق بتاريخ 2026-09-07 |
|---|---|---|
| Alpaca | سجل يومي IEX معدّل للتجزئة، مع ربط وسيط Paper/Live | اختُبر بالمحاكاة؛ مفاتيح حسابك غير متاحة هنا |
| Alpha Vantage | جلب Daily Adjusted كاملًا وإعادة بناء أسعار معدّلة للتجزئة فقط | التطبيق أعاد خطأ داخليًا؛ اختبارات الاستجابات تمت بالمحاكاة |
| Financial Datasets | جلب السجل وترقيم الصفحات؛ يظهر أن تعديل التجزئة غير متحقق | التطبيق رفض الجلب لأن الرصيد صفر |
| TradingCursor | تحليل منفصل متاح في محادثة ChatGPT؛ ليس مصدر تدريب أو اتصالًا تلقائيًا داخل هذا البرنامج | أعاد تحليل AAPL؛ درجة ثقته لم تدخل احتمال النموذج |
| CSV محلي | قبول ملف أسعار من مصدر تختاره، مع التصريح بنوع التعديل | اختُبر التحميل والتحقق محليًا |

إضافات ChatGPT لا تمنح البرنامج المستقل مفاتيحها تلقائيًا. Alpha Vantage يتطلب مفتاحًا وخطة تسمح بـ[Daily Adjusted والسجل الكامل](https://www.alphavantage.co/documentation/#dailyadj). Financial Datasets يتطلب مفتاحًا ورصيدًا مناسبًا؛ [توثيق جلب الأسعار](https://docs.financialdatasets.ai/api/prices/historical). للتبديل إليه:

```bash
.venv/bin/python -m telegram_bridge configure-predictions --provider financial_datasets
```

يعرض مصدر Financial Datasets نتائج استكشافية مع الامتناع عن اعتماد إشارة، لأن مواصفات تعديل التجزئة غير معلنة في الاستجابة الموثقة. لا تخلط بيانات خامًا وأخرى معدّلة في الملف نفسه.

## تجربة فورية بلا مفاتيح

```bash
.venv/bin/python -m telegram_bridge demo --horizon 5
```

هذه **محاكاة مصطنعة باسم DEMO** لا تستخدم أسعار AAPL أو أي سهم حقيقي. لا تعتبر أرقامها دليلًا على نجاح النموذج. تفاصيل المنهج في `PREDICTION_MODEL.md`، وسجل التحقق في `VALIDATION.md`.

لتجربة ملف تملكه دون إعداد Telegram:

```bash
.venv/bin/python -m telegram_bridge predict --symbol AAPL --csv /YOUR_PATH/AAPL.csv --basis split_adjusted --horizon 5
.venv/bin/python -m telegram_bridge backtest --symbol AAPL --csv /YOUR_PATH/AAPL.csv --basis split_adjusted --horizon 5 --json
```

استبدل المسار بمسار ملفك. صيغة CSV: `date,close` مع عمود اختياري `raw_close` للإغلاق الفعلي. `close` يجب أن يكون معدّلًا للتجزئة فقط عند اختيار `split_adjusted`؛ لا تستخدم هذا الخيار لأسعار عائد كلي معدّلة للتوزيعات. يلزم 600 صف يومي على الأقل، وترتيب وتواريخ سليمة. إذا لم تعرف نوع التعديل اترك `--basis` افتراضيًا؛ سيظهر الامتناع عن اعتماد إشارة.

لاستخدام ملفات CSV كمصدر دائم للبوت:

```bash
.venv/bin/python -m telegram_bridge configure-predictions --provider csv --csv-dir /YOUR_PATH/market-data --basis split_adjusted
```

يقرأ كل رمز من ملف مثل `AAPL.csv`. أنت مسؤول عن تحديث هذه الملفات. سجلات أقدم من سبعة أيام تقويمية لا تحصل على توقع سعري حالي. تظل نتيجة الاختبار التاريخي متاحة مع تاريخها.

## الخطوة التالية على الهاتف

1. افتح [BotFather](https://t.me/BotFather) وألغِ مفتاح البوت الذي ظهر في الصورة، ثم أنشئ مفتاحًا بديلًا. يشرح [توثيق Telegram](https://core.telegram.org/bots/features#generating-an-authentication-token) إنشاء مفتاح جديد.
2. افتح [بوتك](https://t.me/Lil_fahad_bot) واضغط **Start**.
3. شغّل الحزمة على كمبيوتر أو خادم دائم. برنامج الإعداد يطلب المفتاح الجديد بحقل مخفي؛ لا تحتاج إلى إرساله في المحادثة أو وضعه في رابط.

## التشغيل على Linux أو macOS

يتطلب Python 3.12 أو أحدث. افتح الطرفية داخل مجلد الحزمة، ثم نفذ:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock
.venv/bin/python -m telegram_bridge setup
.venv/bin/python -m telegram_bridge doctor
.venv/bin/python -m telegram_bridge serve
```

برنامج الإعداد يتأكد من هوية البوت، ويعرض أسماء وأرقام المحادثات التي وصلت إليه، ويطلب منك اختيار المحادثات المسموحة. لا يعتمد تلقائيًا أول شخص يراسل البوت. ثم تنشئ **كلمة مرور مستقلة للربط**، وتختار إن كنت تريد تفعيل أداة الإرسال. القراءة هي الإعداد الافتراضي.

## التشغيل على Windows

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.lock
.venv\Scripts\python.exe -m telegram_bridge setup
.venv\Scripts\python.exe -m telegram_bridge doctor

```

احفظ مجلد `private` في حساب Windows الخاص بك وبصلاحيات تمنع المستخدمين الآخرين من قراءته. أذونات الملفات الرقمية المستخدمة على Linux لا تحل محل صلاحيات Windows.

## إتاحة الخادم لـChatGPT

العنوان المحلي `http://127.0.0.1:8787/mcp` مناسب للتجربة على الجهاز، ولا يصل إليه ChatGPT عبر الإنترنت. للتوصيل من الهاتف تحتاج عنوان HTTPS لخادم التشغيل، أو نفق MCP خاص متاح لحسابك. هذه الحزمة تستخدم OAuth لتسجيل الدخول عند تشغيل HTTP؛ لا تنشرها مع تعطيل المصادقة.

عند توفر نطاقك، شغّل الإعداد بهذا الشكل بدل أمر `setup` أعلاه. استبدل `YOUR_DOMAIN` باسم النطاق الفعلي:

```bash
.venv/bin/python -m telegram_bridge setup --public-base-url https://YOUR_DOMAIN
```

إذا سبق أن أنشأت الإعداد، عدّل فقط `public_base_url` في `private/config.json` إلى عنوان HTTPS دون شرطة مائلة في نهايته، ثم أعد تشغيل الخادم. اتركه يستمع محليًا خلف وكيل HTTPS. تفاصيل النشر في `DEPLOY.md`.

## إضافته إلى ChatGPT

وفق [خطوات OpenAI الرسمية](https://developers.openai.com/plugins/deploy/connect-chatgpt):

1. افتح ChatGPT من المتصفح، ثم **Settings → Security and login → Developer mode** إذا كان متاحًا لحسابك.
2. افتح **Plugins** واضغط **+**، وأدخل `https://YOUR_DOMAIN/mcp`.
3. اختر مصادقة OAuth. الخادم يدعم التسجيل الديناميكي **DCR** باستخدام `client_secret_post` أو `client_secret_basic`، ويعلن بيانات الاكتشاف تلقائيًا.
4. أثناء التفويض أدخل **كلمة مرور الربط** التي أنشأتها في برنامج الإعداد. لا تدخل كلمة مرور حساب Telegram.
5. ثبّت الموصل الخاص في ChatGPT، ثم ابدأ محادثة Work واستدعِ الإضافة. جرّب: «اعرض حالة بوت Telegram»، ثم «اعرض المحادثات المسموحة»، ثم «اعرض آخر الرسائل».

لا يعتبر الاتصال ناجحًا حتى تتم إضافة الخادم وتسجيل الدخول وتشغيل أداة قراءة فعلية بنجاح. توفر Developer mode يعتمد على الحساب وسياسة مساحة العمل.

## حدود التشغيل

- يرد داخل Telegram على أوامر التوقع والمساعدة المحددة بعد تفعيلها. لا يدعم محادثة عامة، ولا ينقل ذاكرة ChatGPT، ولا يحتاج مفتاح OpenAI لتشغيل النموذج الإحصائي.
- يستقبل رسائل البوت والمجموعات أو القنوات التي تسمح إعداداتها له بالوصول. لا يقرأ جميع محادثات حسابك الشخصي أو تاريخها السابق.
- يدعم النص والتعليق على الوسائط. يعرّف نوع الوسائط دون تنزيل الصورة أو الملف أو تفريغ الصوت.
- يحتاج عملية تشغيل مستمرة وقرصًا دائمًا. Telegram يحتفظ بالتحديثات المعلقة مدة لا تتجاوز 24 ساعة؛ الرسائل الفائتة بعد انقطاع طويل قد لا تكون قابلة للاسترجاع. [Telegram Bot API](https://core.telegram.org/bots/api#getting-updates).
- يعرض الرسائل حتى 30 يومًا افتراضيًا. يحذف المستقبِل السجلات الأقدم ويحد العدد بـ10,000 رسالة. إذا توقف الاستقبال، تُحجب الرسائل المنتهية عن أدوات القراءة، ويستأنف الحذف الفعلي عند تشغيله. حذف رسالة داخل Telegram لا يضمن حذف نسختها المحلية فورًا.
- خادم واحد لبوت واحد. عند اكتشاف webhook أو مستقبِل آخر، يتوقف بدل تغيير إعداداته.
- إذا انقطع الاتصال أثناء الإرسال، يعرض نتيجة «غير مؤكدة» ويمنع تكرار نفس طلب الإرسال تلقائيًا.

## الملفات الخاصة والإيقاف

ملف `private/config.json` يحفظ توكن Telegram ومفتاح بيانات السوق محليًا وكلمة مرور الربط بعد تجزئتها. قاعدة البيانات وذاكرة الأسعار في `private/state`. لا ترفع هذا المجلد إلى GitHub. الحزمة المسلّمة لا تحتوي هذه الملفات أو مفتاح الصورة. ذاكرة الأسعار تحتفظ بآخر نسخة لكل رمز طُلب؛ احذف `private/state/market` عند إيقاف الخدمة إذا أردت مسحها. طلبات الأوامر وردودها تخضع لمدة الاحتفاظ بالرسائل.

لإلغاء اتصالات ChatGPT القائمة، مع بقاء رسائل البوت:

```bash
.venv/bin/python -m telegram_bridge revoke-connections
```

لإيقاف الخادم اضغط `Ctrl+C`، أو أوقف خدمة الاستضافة. عند إعادة التشغيل يمكن إكمال رد طلب حديث محفوظ، دون تكرار طلب إرسال مسجل. تُهمَل أوامر أقدم من عشر دقائق، وتُحد الأوامر بخمسة لكل دقيقة لكل محادثة، والطابور بـ100 طلب. لا يتجاوز التشغيل السابق المسموح به أي تعطيل لاحق للتوقعات.

نتائج الاختبار وحدود التحقق في `VALIDATION.md`، وتفاصيل البرمجة في `README.md`.
