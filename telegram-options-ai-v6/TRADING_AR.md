# شراء وبيع الأسهم عبر Telegram — الأوامر اليدوية

تضيف هذه النسخة ربط Alpaca لحساب واحد يملكه صاحب البوت. تدعم شراء الأسهم الأمريكية وبيع الأسهم المتاحة في المحفظة، بكمية صحيحة وسعر محدد بالدولار. تُرسل الصفقة بعد تأكيد صاحب الحساب داخل محادثته الخاصة. هذا الملف يشرح التداول اليدوي. التداول التلقائي التجريبي أصبح متاحًا للحساب الورقي فقط؛ راجع [AUTOTRADING_AR.md](AUTOTRADING_AR.md). التوقع وحده لا يبدأ المحرك.

**البرنامج اختُبر بمحاكاة استجابات الوسيط وTelegram. لم نربطه بحسابك ولم نُجرِ شراء أو بيع فعليًا أو عبر حساب Alpaca تجريبي حقيقي.**

## الإعداد الأول والتحديث

شغّل البرنامج على كمبيوتر أو خادم دائم مع Python 3.12 أو أحدث. تعليمات إعداد Telegram في `README_AR.md` والاستضافة في `DEPLOY.md`. ألغِ التوكن الظاهر في الصورة وأنشئ بديلًا من BotFather؛ لا ترسل التوكن أو مفاتيح الوسيط في المحادثة.

للتحديث: أوقف الخدمة، واحتفظ بمجلد `private` كاملًا، ثم استبدل ملفات البرنامج وثبّت الاعتماديات. لا تحذف قاعدة البيانات ولا تعِد `setup` إذا كان الإعداد موجودًا. قاعدة البيانات القديمة تُحدّث بإضافة جدول الأوامر مع الاحتفاظ بالرسائل والصلاحيات.

```bash
.venv/bin/python -m pip install -r requirements.lock
```

للتثبيت الجديد فقط، نفذ `python3 -m venv .venv` قبل الأمر السابق، ثم `.venv/bin/python -m telegram_bridge setup`.

أنشئ حساب Paper Trading ومفاتيحه من [لوحة Alpaca](https://app.alpaca.markets). الحساب التجريبي يستخدم أموالًا افتراضية ومفاتيح مختلفة عن الحساب الحقيقي؛ شرح الخدمة في [توثيق Alpaca](https://docs.alpaca.markets/us/docs/paper-trading). ثم:

```bash
.venv/bin/python -m telegram_bridge configure-trading --mode paper
.venv/bin/python -m telegram_bridge trading-status
.venv/bin/python -m telegram_bridge serve
```

يطلب الإعداد مفتاح API وSecret في حقلين مخفيين، ويتحقق من هوية الحساب ونشاطه بطلب قراءة. لا يرسل صفقة. إذا لديك أكثر من محادثة خاصة مسموحة، أضف `--chat-id` مع رقم محادثتك الموثّق أثناء `setup`. لا يُختار أول من يراسل البوت تلقائيًا.

الإعداد يفعّل أوامر التداول والتوقعات، ويختار Alpaca IEX مصدرًا للأسعار. يتضمن عرض Alpaca المجاني بيانات IEX؛ وهي بيانات بورصة واحدة وقد تختلف عن الأسعار المجمعة لكل السوق. يتطلب الجلب مفاتيحك المحلية، ولا تنتقل مفاتيح تطبيقات ChatGPT إلى البرنامج. [تغطية البيانات](https://docs.alpaca.markets/us/docs/about-market-data-api)، [تفاصيل IEX](https://docs.alpaca.markets/us/docs/market-data-faq).

## استخدام البوت

أرسل الأوامر بنفسك في المحادثة الخاصة المحددة أثناء الإعداد:

| الأمر | الوظيفة |
|---|---|
| `/account` | نوع الحساب والنقد والقوة الشرائية وأول عشرة مراكز |
| `/buy AAPL 1 200` | معاينة شراء سهم واحد بسعر أقصى 200 دولار |
| `/sell AAPL 1 199` | معاينة بيع سهم مملوك بسعر أدنى 199 دولار |
| `/confirm TICKET` | إرسال المسودة المحددة إلى الوسيط بعد إعادة التحقق |
| `/cancel TICKET` | إلغاء المسودة، أو طلب إلغاء أمر لدى الوسيط |
| `/orders` | متابعة حتى عشرة أوامر للبوت، مع تقديم الإرسالات غير المحسومة |
| `/order TICKET` | تفاصيل أمر محدد وحالته لدى الوسيط |
| `/pause` | إيقاف قبول صفقات جديدة |
| `/resume` | استئناف قبول صفقات تحتاج تأكيدك |
| `/predict AAPL 5` | توقع تجريبي مستقل لخمس جلسات |

**الأسعار والرموز في الجدول أمثلة لصيغة الأوامر وليست أسعارًا حالية أو توصيات.** استبدل `TICKET` بالرمز ذي 12 خانة الذي يولده البوت. يظهر في المعاينة نوع الحساب والرمز والكمية والسعر والقيمة وعرض IEX. تنتهي صلاحية المسودة بعد دقيقتين، وتحتاج عندها إلى طلب جديد بسعر تختاره.

كل أمر `limit` صالح لجلسة اليوم `day`، وفي الجلسة العادية فقط، مع `extended_hours=false`. السعر المحدد لا يضمن تنفيذ الأمر؛ قد ينفذ جزئيًا أو لا ينفذ. يعتمد البرنامج على حالة سوق الوسيط بدل تخمين أيام العطلات. [دورة حياة أوامر Alpaca](https://docs.alpaca.markets/us/docs/orders-at-alpaca).

## الحدود والتحقق

الحدود الافتراضية المحلية هي **500 دولار للأمر، و1,000 دولار لإجمالي أوامر الشراء المقدمة خلال يوم نيويورك، وخمسة أوامر مفتوحة في الحساب**. هذه حدود إعداد للبرنامج وليست مبلغًا موصى باستثماره. يمكن ضبط أول حدين عند الإعداد:

```bash
.venv/bin/python -m telegram_bridge configure-trading --mode paper --max-order-usd 100 --daily-buy-limit-usd 200
```

يُفحص النقد والقوة الشرائية، وحجز الأوامر المفتوحة في الحساب بما فيها الأوامر المنشأة خارجه. البيع يحتاج أسهمًا مملوكة ومتاحة. لا تدعم النسخة البيع على المكشوف أو اقتراض النقد أو الكسور أو الخيارات أو العملات المشفرة. يلزم عرض IEX صالح لا يزيد عمره على دقيقة وسعر محدد لا يبتعد عنه بأكثر من 5%. يعاد الفحص قبل الإرسال؛ أي تعذر في التحقق يوقف الطلب.

سقف الشراء اليومي يخص أوامر هذا البوت، ويحسب الكمية × السعر المحدد عند الإرسال. يحتفظ بالحجز اليومي للأوامر الملغاة أو المنفذة جزئيًا احتياطًا، ويستبعد الأوامر المرفوضة. ليس حدًا للخسارة أو إجمالي نشاط حسابك خارج البوت، ولا يعيد المبلغ اليومي المتاح بعد البيع.

## متابعة الأوامر والإيقاف

قبول الوسيط للطلب لا يعني اكتمال الشراء أو البيع. استخدم `/orders` و`/order` لرؤية الحالة والكمية المنفذة ومتوسط السعر. للأوامر اليدوية تبقى المتابعة عند الطلب. المحرك التلقائي الورقي له متابعة وحالة مستقلة موضحة في AUTOTRADING_AR.md.

يُحفظ معرّف ثابت قبل إرسال الأمر. بعد مهلة اتصال أو انقطاع العملية، يبحث البرنامج عن الأمر بالمعرّف نفسه ولا يعيد تقديمه. تظهر الحالة `unknown` إذا تعذّر الحسم، وتُمنع طلبات جديدة حتى تتضح. إذا استمر الغموض، افحص لوحة Alpaca؛ لا تحذف السجل ولا تنشئ طلبًا بديلًا عشوائيًا. لا توجد آلية تلقائية لتجاوز الحالة المجهولة أو إعادة إرسالها.

رد قبول طلب الإلغاء لا يثبت إلغاء الصفقة؛ قد يسبقه تنفيذ جزئي أو كامل. لا يكرر البرنامج طلب الإلغاء عند فشل الشبكة؛ تابع الحالة ولوحة الوسيط. `/pause` يوقف الإرسالات الجديدة التي لم يبدأ إرسالها، ولا يلغي الأوامر الموجودة ولا يتراجع عن طلب بدأ بالفعل. يحصل `/pause` و`/cancel` على أولوية في طابور الأوامر، لكنهما لا يقاطعان طلبًا جارياً. ويمكن الإيقاف محليًا:

```bash
.venv/bin/python -m telegram_bridge halt-trading
```

## الحساب الحقيقي

بعد تجربتك المستقلة للحساب التجريبي، يمكن تهيئة حساب Alpaca الحقيقي الذي قُبل وفعّله الوسيط. أهلية فتح الحساب والوصول للبيانات يحددها Alpaca. أوقف الخدمة ونفذ محليًا:

```bash
.venv/bin/python -m telegram_bridge configure-trading --mode live
```

أدخل مفاتيح الحساب الحقيقي ثم أعد التشغيل. تظهر كلمة «حقيقي» في المعاينات. لا يوجد تبديل إلى الحساب الحقيقي بأمر Telegram أو من أداة ChatGPT، ولا يستخدم البرنامج مفاتيح Paper للوصول إلى حساب Live. الحساب والمحادثة والبيئة مثبتة على كل مسودة، وتبقى الصفقات بحاجة إلى تأكيدك الفردي. التنفيذ الحقيقي قد يختلف عن المحاكاة من حيث السيولة والأسعار والتكاليف.

## أدوات ChatGPT والبيانات المحلية

بعد التفعيل، أعد تفويض اتصال ChatGPT بالنطاقات المطلوبة: `trading:read` لقراءة الحساب والأوامر، و`trading:prepare` لإنشاء مسودة بمعلمات تختارها، إضافة إلى `telegram:read`. تظهر الأدوات `get_trading_account` و`list_trade_orders` و`prepare_trade`. الأداة الأخيرة لا ترسل صفقة أو رسالة؛ خذ رمز المسودة وأكّدها بنفسك داخل Telegram خلال دقيقتين.

الرسائل المحوّلة والمعدّلة ورسائل المجموعات والبوتات لا تعطي صلاحية تداول. فقط الأوامر الحديثة من صاحب المحادثة المحددة مقبولة. يرفض البرنامج أوامر التداول الأقدم من دقيقتين، ويحد الأوامر العادية بخمسة في الدقيقة.

مفاتيح التشغيل محفوظة محليًا في `private/config.json` بصلاحيات ملف مقيدة، وليست خزنة مشفرة. احمِ حساب النظام والنسخ الاحتياطية. جدول `trades` يحتفظ بمعلمات الأوامر وهويات الحساب وحالاتها بعد انتهاء احتفاظ الرسائل؛ لا يُمسح تلقائيًا لأنه ضروري للمراجعة ومنع التكرار. شغّل نسخة واحدة، واحفظ `private/state` كاملًا عند النقل والتحديث. لا يتطلب التشغيل المستقل اشتراك OpenAI API.
